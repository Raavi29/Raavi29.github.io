U1 In progress

TROPIC01 secure element analysis

de.ci.phe.red Lab, IIT Bhilai / Dr. Dhiman Saha / June 2026 onwards

An independent analysis of Tropic Square's TROPIC01 development kit. A datasheet makes claims about what the chip protects. This project tests them against the hardware. It produced 62 confirmed findings and a conformance test suite that I built and delivered to the lab.

  • USBDescriptor reconnaissance
  • SPIProtocol tested against the conformance spec
  • FirmwareSTM32 firmware decompiled in Ghidra
  • KeysMac-and-Destroy checked across 11 PIN attempts
  • PowerAnalysis with a ChipWhisperer Husky, started

Code and report are lab-restricted, so there is no public repository.

U2 Presented

Intelligent ransomware defence, reviewed

IJCACI 2026 / with Prof. Merry KP / July 2026

A systematic review of machine learning and deep learning ransomware detection across four years of literature, validated in FlareVM and REMnux. It found a gap between detection accuracy and forensic recoverability. RansomGuard starts there.

Accepted and presented. The publishing contract is signed and the paper is not in print yet.

U3 Early build

RansomGuard

Solo project / architecture phase

A ransomware detector that collects forensic evidence at the moment it fires. A spike in file entropy or a process deleting shadow copies triggers a snapshot of the affected files, the process tree and the network state, with a timestamped evidence chain.

Python, watchdog, psutil, scikit-learn, SQLite, Streamlit. Runs only against synthetic ransomware-like behaviour in a sandbox. No benchmark results yet.

Break a key

A simulated power-analysis attack, the technique I am learning on the ChipWhisperer. Add power traces and watch the secret key byte stand out from 255 wrong guesses.

real key byteattacker's best guessother guessesEach bar is one of the 256 possible key bytes. Height is how well that guess matches the power readings.

Simulated leakage: the Hamming weight of an AES S-box output plus random noise. It uses no data from any real device and none from my lab work.
